# incentive-mechanism-validation

Tier 1 Monte Carlo validation results for the Tri-Tier Tuning Model (3TTM), reported in Chapter 5 of the PhD thesis by Chien-Chih Chen (University of Waterloo).

- `results/mc_validation/Tier1_MC_Validation_Odd_Main.csv.csv`: odd-size committees (main validation)
- `results/mc_validation/Tier1_MC_Validation_Even_Tie.csv.csv`: even-size committees (tie verification)

These files were first kept in a University of Waterloo GitLab repository and are copied here unchanged.
